## Cómo se usa

1. Instala [Claude Code](https://claude.com/product/claude-code).
2. Descarga este proyecto y abre una terminal dentro de la carpeta.
3. Escribe `claude` y presiona Enter.
4. La primera vez, Claude Code te pregunta si confías en esta carpeta: responde que sí. Eso activa los permisos del kit (puede crear tu página en `sitio/` sin preguntarte por cada archivo).
5. Saluda y responde las preguntas. Claude te guía hasta tener tu página lista.
